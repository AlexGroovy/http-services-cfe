# Подсистема Example — описание изменений

Демонстрационный пример HTTP API поверх инфраструктуры HTTP-сервисов расширения. Ниже — изменения **только объектов подсистемы `Example`**.

## Состав подсистемы

| Объект | Назначение |
|--------|------------|
| `HTTPСервис.Example` | HTTP-сервис, корневой URL `example` |
| `Справочник.Example_Контрагенты` | Контрагенты (ИНН, КПП, признак недействительности) |
| `Справочник.Example_Договоры` | Договоры, подчинённые контрагентам |
| `ОбщийМодуль.ОбработчикиHTTPСервисЗапросов` | Обработчики и проверки запросов API |
| `ОбщийМодуль.HTTPСервисЗапросыПереопределяемый` | Точки расширения инфраструктуры (без изменений логики Example) |

Контракт OpenAPI: [`schema.json`](schema.json) (версия API `1.0.1.1`).

---

## HTTPСервис.Example

### Шаблоны URL и методы

| Шаблон | Метод | Обработчик | operationId |
|--------|-------|------------|-------------|
| `/echo` | POST | `Echo` | `Echo` |
| `/contragents` | GET | `GetContragents` | `GetContragents` |
| `/contragents` | POST | `CreateContragent` | `CreateContragent` |
| `/contragents/{inn}/contracts/` | GET | `GetContracts` | `GetContracts` |

### Что изменилось

1. **Echo** — метод HTTP сменён с `HEAD` на `POST` (соответствует схеме OpenAPI).
2. **CreateContragent** — переименование обработчика `CreateContragents` → `CreateContragent`.
3. **GetContracts** — шаблон URL:
   - было: `/contracts/{inn}/*`
   - стало: `/contragents/{inn}/contracts/`

## Справочник.Example_Контрагенты

### Реквизиты (актуальные)

- `ИНН` — обязательный для заполнения
- `КПП`
- `Недействителен`

### Модуль менеджера

| Метод | Описание |
|-------|----------|
| `СоздатьКонтрагента(ОписаниеКонтрагента)` | Создаёт элемент, проверяет заполнение и **записывает** объект |
| `АктивныеКонтрагенты()` | Выборка активных контрагентов (не группа, не помечен на удаление, не недействителен) |

### Что изменилось

1. После `ПроверитьЗаполнение()` добавлен вызов `Контрагент.Записать()`.
2. Метод `СписокАктивныхКонтрагентов` переименован в `АктивныеКонтрагенты`.
3. Исправлена ошибка в тексте запроса (`И НЕ` → `НЕ` в условии `ГДЕ`).

## Справочник.Example_Договоры

Подчинён `Example_Контрагенты` (владелец). Реквизиты: `Номер`, `Дата`.

### Что изменилось

1. Для реквизита **Номер** включена проверка заполнения (`ShowError`).
2. Добавлен модуль менеджера с методом `ДоговорыКонтрагента(ИНН)`:
   - возвращает договоры активного контрагента по ИНН;
   - без помеченных на удаление;
   - поля: `Ссылка`, `Наименование`, `Номер`, `Дата`.

## ОбщийМодуль.ОбработчикиHTTPСервисЗапросов

### Регистрация обработчиков

| HTTP-сервис (предопределённый) | Обработчик | Привилегированный режим |
|--------------------------------|------------|-------------------------|
| `Echo` | `ОбработатьЗапросEcho` | нет |
| `GetContragents` | `ОбработатьЗапросGetContragents` | да |
| `CreateContragent` | `ОбработатьЗапросCreateContragent` | да |
| `GetContracts` | `ОбработатьЗапросGetContracts` | да |
| `GetContracts` (проверка) | `ПроверитьЗапросGetContracts` | да |

### Логика по операциям

**GetContragents** — список через `Example_Контрагенты.АктивныеКонтрагенты()`, ответ: массив `{ name, inn, kpp }`.

**CreateContragent** — создание контрагента по телу `{ name, inn, kpp }` (вместо прежней логики продажи билетов).

**GetContracts**:

1. Проверка: заполнен `inn` в URL; контрагент с таким ИНН существует (иначе 400).
2. Выборка договоров через `Example_Договоры.ДоговорыКонтрагента(ИНН)`.
3. Ответ: массив `{ id, name, number, date }`, где `date` — строка `yyyy-MM-dd` (требование OpenAPI `format: date`; тип `Дата` не проходит автопроверку ответа).

## Схема OpenAPI (`schema.json`)

| Было | Стало |
|------|-------|
| `/kungfu/echo` | `/echo` |
| `CreateContragents` (client + tickets) | `CreateContragent` (`inn`, `kpp`, `name`) |
| `/contracts/{inn}/*`, поля `type`, `count_visits` | `/contragents/{inn}/contracts/*`, поля `number`, `date` |

Общие коды ошибок: `400`, `403`, `500` — формат `{ "errors": [ { "message": "..." } ] }`.

## Примеры запросов

Базовый URL публикации (пример): `http://localhost/<ИБ>/hs/example`

```http
POST /echo
Content-Type: application/json

{ "request": "ping" }
```

```http
GET /contragents
```

```http
POST /contragents
Content-Type: application/json

{ "name": "ООО Ромашка", "inn": "111111111111", "kpp": "111111111" }
```

```http
GET /contragents/111111111111/contracts/
```

## Настройка в ИБ после обновления

1. Загрузить расширение / обновить конфигурацию.
2. В справочнике **СхемыHTTPСервисов** обновить схему из `schema.json`.
3. В справочнике **HTTPСервисы** для предопределённых элементов `Echo`, `GetContragents`, `CreateContragent`, `GetContracts` указать схему, `operationId` и включить сервис.
