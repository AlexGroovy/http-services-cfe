Регистр сведений «Лог HTTP запросов»

Регистр сведений «Лог HTTP запросов» предназначен для записи и хранения информации о параметрах входящих HTTP-запросов.

Параметры извлекаются из входящего HTTP-запроса и представлены в удобном для чтения и анализа виде.

В логе хранятся такие параметры запросов как: дата запроса, URL запрашиваемого ресурса, сервис, параметры из тела запроса и из URL, код состояния и ответ HTTP-сервиса клиенту.
